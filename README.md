# TrabajoFinal — Análisis y Predicción (Speed Dating)

Proyecto en **C** para la lectura, normalización, entrenamiento y evaluación de precisión sobre el dataset **Speed Dating** (speeddating.csv).

## Estructura principal
- main.c / matriz.c / matriz.h: Carga e impresión de matrices de datos desde CSV.
- 
ormalizar.c / 
ormalizar.h: Normalización de atributos numéricos.
- crearMatriz.c, escribirCSV.c: Generación y exportación de conjuntos de datos (entrenamiento50.csv, prueba50.csv, 
uevos_datos.csv).
- contarMatch.c, precision.c, precision1K.c: Evaluación de coincidencias y cálculo de precisión.
- interactivo.c: Modo interactivo por consola.
- makefile: Compilación del proyecto.
